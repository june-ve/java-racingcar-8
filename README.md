# 자동차 경주

---

## 기능 목록

### 1. 자동차 이름 입력 기능
- [ ] 쉼표(,) 기준으로 자동차 이름 입력받기
- [ ] 잘못된 입력일 경우 `IllegalArgumentException`  발생 후 종료
    - [ ] 최소 두 대 이상인지 검증 (`,` 포함 필수)
    - [ ] 각 자동차 이름이 비어있거나 공백일 경우
    - [ ] 각 자동차 이름이 1~5자 범위인지 검증

### 2. 시도 횟수 입력 기능
- [ ] 시도할 횟수 입력받기
- [ ] 잘못된 입력일 경우 `IllegalArgumentException` 발생 후 종료
    - [ ] 숫자 여부 검증
    - [ ] 1 이상이 아닌 경우

### 3. 전진 조건 처리
- [ ] 0~9 범위의 무작위 값 생성하여 전진 기준값(기본 4) 이상일 경우 한 칸 전진

### 4. 게임 실행 (시도 횟수만큼 반복)
- [ ] 각 라운드마다 모든 자동차 이동 처리
- [ ] 이동 결과 출력

### 5. 우승자 판별 기능
- [ ] 가장 멀리 이동한 자동차 찾기
- [ ] 최종 우승자 출력
    - [ ] 공동 우승자 가능 → 쉼표(,)로 구분하여 출력
