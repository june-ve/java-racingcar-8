# 자동차 경주

사용자로부터 자동차 이름과 시도 횟수를 입력받아,
입력된 횟수 동안 자동차 경주를 진행하고 최종 우승자를 출력한다.

---

## 🚗 기능 목록

### 1. 자동차 이름 입력 기능
- [x] 쉼표(,) 기준으로 자동차 이름 입력받기
- [x] 잘못된 입력일 경우 `IllegalArgumentException`  발생 후 종료
  - [x] 최소 두 대 이상인지 검증 (`,` 포함 필수)
  - [x] 각 자동차 이름이 비어있거나 공백일 경우
  - [x] 각 자동차 이름이 1~5자 범위인지 검증

### 2. 시도 횟수 입력 기능
- [x] 시도할 횟수 입력받기
- [x] 잘못된 입력일 경우 `IllegalArgumentException` 발생 후 종료
  - [x] 숫자 여부 검증
  - [x] 1 이상이 아닌 경우

### 3. 전진 조건 처리
- [x] 0~9 범위의 무작위 값 생성하여 전진 기준값(기본 4) 이상일 경우 한 칸 전진

### 4. 게임 실행 (시도 횟수만큼 반복)
- [x] 각 라운드마다 모든 자동차 이동 처리
- [x] 이동 결과 출력

### 5. 우승자 판별 기능
- [x] 가장 멀리 이동한 자동차 찾기
- [x] 최종 우승자 출력
  - [x] 공동 우승자 가능 → 쉼표(,)로 구분하여 출력

## 🚕 클래스 설계

| 패키지 | 클래스                | 책임 | 비고                             |
|--------|--------------------|------|--------------------------------|
| domain | `Car`              | 자동차 1대의 상태(name, position) 관리 및 이동(move) | 도메인 불변성 유지를 위해 생성자에서 유효성 검증 수행 |
| service | `RacingGame`       | 자동차 목록을 바탕으로 1회 이동 처리 및 우승자 판별 | 비즈니스 로직의 중심 역할 (게임 규칙 담당)      |
| controller | `RacingController` | 입력 → 게임 실행 → 출력의 흐름 제어 | 비즈니스 로직 없음, 흐름 제어만 담당          |
| view | `InputView`        | 콘솔 입력 전담 (Console.readLine) | 검증은 View에서 하지 않음 (SRP 유지)      |
| view | `ResultView`       | 라운드 진행 결과 및 최종 우승자 출력 | 출력 형식 처리 담당                    |
| util | `CarNamesParser`   | 사용자 입력 문자열을 파싱하여 자동차 이름 리스트로 변환 & 유효성 검증 | View와 도메인의 중간 단계               |
| util | `TryCountParser`   | 시도 횟수 입력값 파싱 및 정수 변환 + 유효성 검증 | 잘못된 입력은 즉시 예외 처리               |
| root | `Application`      | 프로그램 실행 진입점(main 메서드) | Controller 실행만 담당              |

---

## 🚗 예외 처리 기준

| 상황 | 조치 |
|------|------|
| 자동차 이름이 2대 미만 | `IllegalArgumentException` |
| 공백/빈 문자열 입력 | `IllegalArgumentException` |
| 이름 길이 1~5자 범위 벗어남 | `IllegalArgumentException` |
| 시도 횟수가 숫자가 아님 | `IllegalArgumentException` |
| 시도 횟수가 1 미만 | `IllegalArgumentException` |
